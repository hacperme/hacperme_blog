# USB 快充技术全景：从 5V 到 240W 的演进之路

> 基于知识库 USB 供电专题整理：Maker電子學《USB 电源供应彻底研究》9 篇 + TI《USB Type-C 和 USB PD 电子书》+ 充电头网拆解/方案（南芯 SC8724、智融 SW3578、英集芯 IP2366 等）。对做嵌入式电源、快充产品、Type-C 设备选型的工程师有参考价值。

做嵌入式硬件，USB 充电是绕不开的一环。从早年 USB 1.1 的 5V/100mA，到今天 USB PD 3.1 的 48V/5A/240W，USB 的供电能力翻了 **960 倍**。这篇文章把这条演进路线的关键节点串起来：电流的本质、快充识别战争、Type-C 革命、PD 协议协商，以及芯片方案速览和工程避坑。

## 一、USB 供电简史：从"偷电"到正式供电

USB 从设计之初就包含供电，但早期设备经常"偷电"：

- **RS-232C 偷电**：RTS/DTR 强制逻辑 0（+5~+15V）→ 滤波稳压当电源，每脚 3-4mA，两脚共 6-8mA（够驱动鼠标）
- **HDMI 偷电**：+5V 脚供 EDID EEPROM（规格 50mA，用不完 → 偷来用）；HDMI 2.1 起官方支持 **HDMI Cable Power 5V/300mA**
- **USB 1.1**：5V±5%，4 脚（VBUS/GND/D+/D-）；**枚举前最大 100mA，枚举后按 descriptor 最大 500mA**

## 二、电流由负载决定（核心原理）

**5V/1A 充电器 = 最大 1A 的 5V 电压源**，实际电流由负载 R 决定（V=IR）：

- ⚠️ **"用大充电器充小手机烧坏手机"是谣言**：电压正确就不会烧（5V/1000A 点焊机充手机也只流 1A）
- **反过来的风险**：5V/0.5A 充电器被 1A 负载过载 → 压降或断电保护
- 功率限制来源：转换效率 + 热耗散；满载 5W 需 5.55W 输入（90% 效率），0.55W 变热

**C 率与充电功率**：1000mAh 电池用 1000mA = 1C，1C 充电约 1 小时。锂电 CC 后 CV（4.2V 截止），1C 充不满 1 小时 → 需 >1C。计算：3000mAh × 1.5 = 4.5A × 3.7V = 16.65W → 加 buck 损耗 → 5V 输入需 18.5W = **3.7A**（远超 Type A 规格）——这就是快充必须突破 5V 的原因。

## 三、快充识别战争：D+/D- 分压识别

早期快充靠 **D+/D- 电压识别**充电器能力（HVDCP）：

| 厂商 | D+/D- 电压 | 快充能力 |
|------|-----------|---------|
| **Apple** | 分压电阻不同电压 | 5W/10W/12W（2.7V=12W） |
| **Samsung** | 都是 **1.2V**（可共电阻） | 5V/2A=10W |
| **Sony** | 都是 **3.3V**（可共电阻） | 最大 2A |

⚠️ **兼容性差**：Sony 充电器充 iPhone（3.3V 不认）→ 500mA 慢充；iPhone 充电器充 Sony（2.7V 不认）→ 慢充。

**QC（Quick Charge）思路**：Type A 电流上限 1A（早期）/3A（通用）/5A（特殊）→ 5V 下最多 25W，平板/笔电不够。**QC 提高 VBUS 电压**（最大电流不变 → 功率↑）：

- **QC 2.0**：Class A（5/9/12V）+ Class B（+20V）；**20V 是安规门槛**（UL3010，<20V 认证容易 → 笔电 19.5V 充电器原因）
- **QC 3.0**：脉冲调压（D+ 上 0.6→3.3→0.6V pulse → VBUS +0.2V；D- 反向 → -0.2V），可连续调整任意电压

## 四、Type-C 革命：24 脚、无正反、无主从

Type-C（USB 3.1 推出）**24 脚、无正反、无 host/device 区分**：

- 信号 12 个 ×2 镜像（A1-12/B1-12 相同信号并联 → 正反可插）；**SBU/CC 不镜像**
- **CC1/CC2 是关键**：Rp/Rd 电阻辨 source/sink
- **角色**：source（供电）/ sink（吃电）/ **DRP**（双角色，自动判断）
- ⚠️ **DRP-DRP 冲突**：iPhone 15（DRP）连移动电源（DRP）→ 随机决定角色，可能反向充电（手机给充电宝充）。双 Type-C 口移动电源（一口固定 source 一口固定 sink）可避免

## 五、USB PD 协议：从 2.5W 到 240W

### 功率级别演进

| 规范 | 最大电压 | 最大电流 | 最大功率 |
|------|---------|---------|---------|
| USB 2.0 | 5V | 500mA | 2.5W |
| USB 3.0/3.1 | 5V | 900mA | 4.5W |
| USB BC 1.2 | 5V | 1.5A | 7.5W |
| **USB-C 1.2** | 5V | 3A | **15W** |
| **USB PD 3.0** | 20V | 5A | **100W** |
| **USB PD 3.1** | 48V | 5A | **240W** |

- 无 PD 的 USB-C 最高 5V/3A/15W；有 PD 最高 48V/5A/240W
- **PD 3.2 SPR AVS**：iPhone 17 系列率先全面采用（AVS 可调电压供电），存量 PD3.0/PPS 适配器可通过 AVS 桥接方案支持

### PD 协商流程（4 步）

```
1. Source 检测电缆功能/插头类型 → 发送 Source_Capabilities（电源能力）
2. Sink 策略引擎评估能力、选电源 → 发送 Request
3. Source 策略引擎评估请求 → 发送 Accept（附 CRC）
4. Source 稳定输出 → 发送 PS_RDY（附 CRC）→ 开始供电
```

- **DR_Swap（数据角色交换）**、**PR_Swap（电源角色交换，5 步）**：连接后可动态换角色
- PD 协议复杂，需 MCU（TI/ST 的 PD Controller 内建 Cortex-M0）

### PD 诱骗器

**CH224K**（南京沁恒 WCH，ESSOP-10）：sink 端 PD 协议控制 IC，DIP switch/电阻设定请求 5/9/12/15/20V。用途：从 PD 充电器/移动电源拿指定电压（无需完整 PD 实现）——研发/产线/售后测电压的利器。

## 六、芯片方案速览（结合知识库）

| 类别 | 芯片 | 厂商 | 关键参数 |
|------|------|------|---------|
| 移动电源 SoC | IP5356 / IP5407 | 英集芯 | 22.5W 快充，QC/PD 协议 |
| 双向 Buck-Boost | SC8815A | 南芯 | PD 充电管理 |
| 升降压转换器 | SC8724 | 南芯 | 2.7-22V 输入 / 3-22V 输出 / 10A，250k-1MHz |
| I2C 充电器 | ETA6963 / SGM41513 / UPM6910DK | 钰泰/圣邦微/芯合 | 3A + Power-Path + OTG |
| 线性充电器 | TP4056 / LP4076B | 拓微/微源 | 5V 基础充电 |
| 降压协议 SoC | SW3578 | 智融 | 10A Buck + 32 位 MCU + 双 C 逻辑，一芯三充 |
| 多串充放电 | IP2366 | 英集芯 | PD3.1 140W 多串锂电 |
| PD 诱骗器 | CH224K | 沁恒 WCH | 请求 5/9/12/15/20V |

**架构趋势**：固定母线架构 + 二次 DC-DC 是主流——前级 GaN 电源固定电压输出 → 升降压（SC8724 等）→ 各接口独立调压。宽压特性（2.7-22V）适应多路供电灵活需求。

## 七、工程避坑清单

1. **电压正确就不会烧设备**：电流由负载决定，别被"大充电器烧手机"谣言误导
2. **Type A 电流上限**：1A（早期）/3A（通用）/5A（特殊）——5V 下最多 25W，更高必须 PD
3. **20V 是安规门槛**（UL3010）——笔电 19.5V 充电器的原因
4. **DRP-DRP 反向充电**：双 C 口设备注意固定 source/sink 角色
5. **PD 3.1 EPR 注意**：48V 高压需要 e-marker 电缆（USB-C 电缆能力协商）
6. **AVS 是 PD3.2 新特性**：iPhone 17 生态，存量 PD3.0 适配器需桥接方案
7. **GaN 移动电源难点**：不是器件，是系统工程——100W 双向升降压高 dv/dt 引发门极串扰/共模 EMI，GaN 门极耐压窗口窄，塑料外壳散热差
8. **多口并发功率路径**：多口充电路径与限功率策略设计复杂度高，认证成本上升

## 八、一句话总结

**USB 充电的演进 = 电压/电流/协议的不断解锁**：从 5V 固定电压（电流由负载决定）→ QC 提压（5→20V）→ Type-C 统一接口（CC 协商）→ PD 协议化（48V/240W 可编程）→ PD3.2 AVS（可调电压）。做产品时，先定功率档位（≤15W 免 PD / ≤100W PD3.0 / ≤240W PD3.1），再选芯片方案（充电管理 + 升降压 + 协议 SoC），最后注意 e-marker/安规/散热这些"看不见的成本"。
