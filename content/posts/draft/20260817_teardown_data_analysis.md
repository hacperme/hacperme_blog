# TWS 与音频设备拆解大数据：898 份拆解按产品分类解析

> 基于个人知识库 **898 份拆解报告**（我爱音频网 52audio 全站 + 充电头网电源拆解）按产品分类的数据分析。每类产品拆开看：技术方案、主控选型、厂商格局、发展趋势。

收集拆解报告是了解行业最快的路径——每一份拆解都是一次真实的 BOM 曝光。过去两年我在知识库里累积了 898 份拆解，覆盖 2017-2026 几乎所有主流音频/充电产品。这篇按**产品分类**盘数据：**TWS 耳机、智能音箱、颈挂耳机、AI 眼镜、可穿戴、电源充电**六大品类，各自的技术路线与选型参考。

## 一、数据全景（按产品分类）

| 品类 | 拆解数 | 占比 |
|------|--------|------|
| **TWS 真无线耳机** | 690 | 77% |
| **智能音箱** | 101 | 11% |
| **充电器/电源** | 35 | 4% |
| 颈挂/运动耳机 | 23 | 3% |
| AI 眼镜/AR | 17 | 2% |
| 可穿戴（手表/戒指） | 14 | 2% |
| 无线麦克风 | 8 | 1% |
| 其他（风扇/机器人等） | 10 | 1% |

**TWS 独占 77%**——这是过去十年音频行业绝对主战场。

### 技术趋势（TWS）

3. **带屏仓兴起**：BT8959T / AC982A1 带屏方案（2023+）
4. **AI 上耳**：BES2800 + NPU、物奇 WQ7036 + 大模型

## 四、颈挂/运动耳机（23 份）——CSR 时代遗留

### 主控格局
| 主控 | 厂商 | 次数 |
|------|------|------|

| **AB1532 / AB1526P** | 达发 | 4 |

### 洞察
- 颈挂耳机是 **CSR 时代（2018-2020）主力**，CSR8645 出现 5 次
- 已被 TWS 取代，2021 后新品骤减
- 达发（络达）在颈挂/运动场景延续（AB 系列）

## 五、AI 眼镜/AR（17 份）——新品类爆发

### 主控格局
| 主控 | 厂商 | 次数 | 代表 |
|------|------|------|------|
| **BES2800BP** | 恒玄 | 2 | 夸克 AI 眼镜协处理器 |
| **W517** | 紫光展锐 | 2 | DPVR VisionRay |
| **骁龙 AR1** | 高通 | 1 | 夸克 AI 眼镜 |
| **RTL8753BFE** | 瑞昱 | 1 | 影目 INMO GO3 |

### 五路线成型（AI 眼镜）
1. **端侧 AI SoC**：骁龙 AR1 / W337 / W517（AI 拍摄）
2. **音频眼镜**：BES 系（耳机+眼镜）
3. **观影显示**：Pixelworks + 龙迅（无 SoC 显示链路）
4. **拍照眼镜**：高通 W5 穿戴平台
5. **AR 光机**：影目自研光机 + 展锐

### 趋势
- **AI 眼镜是 2025-2026 最热新品类**：夸克/小米/华为/影目全入局
- 主控多路线并行（展锐/高通/恒玄），尚无统一标准
- 显示链路（Micro-OLED + 光波导）与音频主控分离

## 七、充电器/电源（35 份）——数字电源化

### PFC 主控三路线
| 路线 | 代表芯片 | 功率段 |
|------|---------|--------|
| 模拟 CCM PFC | TI UCC28180 | 300W |
| 模拟 PFC/PWM 二合一 | 虹冠 CM6800 | 320W |
| **数字 PFC（MCU）** | TI C2000 / STM32G474 | 550W-2030W |

### 第三代半导体
- **GaN**：英诺赛科（INN650TA080BS）进入公牛/OPPO/小米/安克，出货 20 亿颗
- **SiC**：科锐 C3D10065A / 平伟 DESC1065W——服务器电源 PFC 整流标配
- **PD 演进**：PD3.0 100W → PD3.1 240W → **PD3.2 AVS**（iPhone 17）

### 电源管理芯片（TWS 侧）
- 充电仓 SoC：英集芯 IP 系（垄断）
- 保护 IC：DW01 + 8205 经典组合（38+34 次）、创芯微 CM1126B
- 升降压：南芯 SC8724（10 产品应用）、智融 SW3578

## 八、国际品牌芯片路线（跨品类洞察）

| 品牌 | 芯片路线 |
|------|---------|
| 苹果 | 全自研（W1/H1/S5/U1/A8/A19） |
| 三星 | 自研电源 MUA01 + **恒玄 BES2700**（Buds Core） |
| Beats | H1 / W1 / **联发科 MT2821A** 三路线 |
| Bose | **NXP QN9080**（非高通） |
| JBL | 国产：中星微 / 炬芯 / 艾为 |
| 索尼 | 自研 V1 + 达发 + 联发科多路线 |
| Marshall | QCC3046 → **达发 AB1565M**（平台切换） |

**核心洞察**：国际大厂全面拥抱国产芯片——**Bose 用 NXP、Beats 用联发科、JBL 用国产、三星用恒玄**。

## 九、总结：六大品类一句话

| 品类 | 一句话结论 |
|------|-----------|
| **TWS** | 恒玄领跑 + 英集芯仓 SoC 垄断 + AI 上耳 |
| **智能音箱** | 全志/联发科/炬芯/晶晨/高通/杰理六路线 |
| **颈挂** | CSR 时代遗留，已被 TWS 取代 |
| **AI 眼镜** | 2025-26 最热新品类，主控五路线并行 |
| **可穿戴** | 健康监测化，戒指新品类 + 手表国产化 |
| **电源** | 数字 PFC + GaN/SiC + PD3.2 AVS |

**做硬件选型时，国产芯片已从"备选"变"主力"**——这是 898 份拆解最一致的结论。
